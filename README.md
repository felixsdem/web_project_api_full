# Tripleten web_project_api_full

## Descripción

Aplicación web basada en el proyecto Around, con autenticación de usuarios, creación y gestión de tarjetas, perfiles de usuario y sistema de likes.

El proyecto está dividido en un frontend desarrollado con React y un backend desarrollado con Node.js, Express y MongoDB.

## Tecnologías

### Frontend

- React
- Vite
- JavaScript
- HTML
- CSS

### Backend

- Node.js
- Express
- MongoDB
- Mongoose
- JWT
- bcrypt
- Celebrate / Joi
- Winston
